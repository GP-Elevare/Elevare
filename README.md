# How to run (MUST install node js first)

- install ffmpeg by opening PowerShell as Administrator and running `winget install ffmpeg`

- Open 2 terminals
- in the first one type:
  - cd client
  - npm install (run only once)
  - npm run dev
- in the second one type:
  - cd server
  - npm install (run only once)
  - node index.js
